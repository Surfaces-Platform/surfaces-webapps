# p0004 - Task-First Governance UX

Derived from p0003.

This iteration shifts governance from data-heavy display to activity-focused workflow:

- Default mode is draft editing.
- Snapshot review is modal and opened only when needed.
- Full draft contract views are hidden behind an explicit drawer.
- Scope controls are available via settings popover, not always-on sidebar.
- Publish remains globally visible with disabled reason feedback.
