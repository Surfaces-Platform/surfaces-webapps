Tide prototype — run opus-d (baseline, resource: none)

Outcome

Single-screen responsive React 19 tide app built from the fresh starter and unchanged public/data.js (14 locations × 2 dates). - Controls: location <select> (14 stations) and a two-button day toggle (Tue Oct 6 / Wed Oct 7). Initial selection: Half Moon Bay, 2026-10-06. - Reading card: station, full date and "at 12:00 PM PT" clock, current height (m), Rising/Falling (arrow + word + colour), next high and next low (time PT + height), ordered by which comes first. - 24-hour chart (inline SVG): smooth curve through all 25 hourly samples (0–24 h), metre gridlines, labelled hour axis, H/L event markers with heights, dashed noon marker with current height. Y scale is computed per selection (0 to rounded-up max with headroom, 0.5 m or 1 m steps) so it always contains the data. Mobile uses a narrower chart geometry so labels stay legible. Event list under the chart; SVG has a text aria-label summary. - Light mode only (color-scheme: only light, no dark media rules); system fonts; no banners/notices; no network calls. - Files changed: src/App.jsx, src/styles.css. Added QA script evidence/sweep.cjs. Starter build/check/data unchanged.
