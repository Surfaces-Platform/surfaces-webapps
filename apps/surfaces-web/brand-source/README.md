# Surfaces site brand sources

The contract pins the three canonical mark sources and both complete horizontal lockups from the approved brand package at `1d29168a9d35bc4f45de857afd7b43ea404532f8`. The primary horizontal files remain byte-identical to that package. Keep all three slab coordinates, the Nickel lower slab, and the complete outlined Inter 780 wordmark.

Rebuild from the repository root with Python 3 and ImageMagick:

```sh
python3 scripts/build-surfaces-site-brand.py
python3 scripts/build-surfaces-brand-kit.py
python3 scripts/build-surfaces-site-brand.py --check
```

The default generator consumes checked-in vector outlines and needs no installed font. It writes versioned browser PNG/SVGs, opaque touch/install PNGs, conventional aliases, a web manifest, two 1200 by 630 social PNGs, and source/output fingerprints. The legacy social PNG URL receives the same current bytes. Metadata advertises versioned PNG URLs so fresh crawls request the canonical composition.

`design-system-social-copy.svg` preserves the existing two lines of reference-card copy as Inter 760 outlines at 58 px and optical size 32. The optional `scripts/outline-surfaces-social-copy.swift` helper prepares these paths using CoreText and checks the exact Inter font fingerprint; it is unnecessary for normal builds. The brand name always comes from the approved Inter 780 lockup. Do not outline or retype it again.

Touch and install icons have an opaque Ink plate. Their mark uses the master geometry at a uniform 0.75 scale, centered inside the maskable safe circle. Browser SVGs remain transparent and switch with system theme. Safari pinned-tab icons use the canonical one-color master because the platform applies a single tint; full-color icons retain Nickel.

When an approved source changes, update its contract fingerprint and use a new revision path before rebuilding. Focused tests verify every declared export hash, dimensions, metadata references, ICO frames, and manifest assets. `--check` also rerenders to a temporary directory and fails if generated bytes drift.
